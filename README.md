# 刻时 KESHI

> 不是又一个待办清单，而是一条会呼吸的时间轴——把每一分钟放回它该在的位置，并在正确的时刻，用你喜欢的音乐提醒你。
> 副标题：把忙碌，过成节奏。

面向大学生（20 岁左右）的分钟级任务与提醒管家。手机为主、电脑做周计划；无需注册，私人日程不上云。

## 如何运行

```bash
npm install
npm run dev        # 开发（http://localhost:5173）
npm run build      # 生产构建到 dist/
npm run preview    # 本地预览构建产物
```

仅依赖 React 18 + TypeScript + Vite，无后端、无登录、无云同步、无外部 AI 接口。

## 数据存储位置

- **任务 / 设置 / 铃声元数据**：浏览器 `localStorage`（key `keshi:state:v2`）。
- **音乐文件原始 Blob**：浏览器 `IndexedDB`（库 `keshi-db`，对象仓库 `audio`）。**绝不上传服务器**，只保存在本机，刷新页面后仍可播放。
- 导出备份为 JSON（`keshi-backup-*.json`），**不包含音乐文件**；导入后任务与设置恢复，音乐需重新上传。

## 提醒可靠性边界（请如实了解）

- 页面**保持打开、处于前台**时，提醒误差控制在 **±1 秒**（单次 `setTimeout` 指向最近事件，触发后重算）。
- 页面切到**后台**，浏览器会限流定时器，提醒可能延迟。
- 页面**完全关闭 / 手机锁屏**后，**Web 版无法保证响铃**——这是浏览器平台的硬边界，本应用不伪装成系统闹钟。
- 多标签页：通过 `BroadcastChannel` 同步数据 + `localStorage` 心跳锁，**只有一个标签负责响铃**，关闭后可被其他标签接管。
- 系统通知只是**补充**（需主动授权，拒绝后不再请求），应用内全屏提醒始终可用。

## 核心功能

- **三幕提醒链**：T-30 安静预演卡（不播声）→ T-10 轻声短铃 + 清单 + 出发建议 → T-0 全屏接管、播放你的音乐（3 秒淡入到 60%）。
- **升级逻辑**：45 秒无操作音量渐进到 75%、光环增强；90 秒再短提示最多两次后停止，保留常驻卡（可在设置关闭）。
- **本地音乐工作台**：上传/拖拽 mp3·wav·m4a·ogg（≤20MB），实时波形、双手柄裁剪 3–60 秒、淡入淡出、循环、音量，存 IndexedDB。
- **任务声纹**：提醒声按任务分类/优先级/时段本地规则合成 4–8 秒提示音（学习=低频柔和、社团=暖色、紧急加脉冲、深夜降亮度降音量、课堂静音）；同一类稳定不变、不随机；本地音乐优先，生成失败回退内置音色。
- **分钟级时间轴**：任务按真实分钟定位，15 分钟网格只做视觉刻度；金色「现在线」、重叠提示、空档点击快建、拖动改时间/拉伸改时长（吸附 5 分钟）。
- **本周视图**（`#/week`）：周一至周日 7 列，任务按真实时间定位、截止单独归区；上一周/下一周跨月跨年正确、按学期显示「第 N 周」；桌面 7 列可横滚，移动端 7 日条 + 选中日时间轴；过滤「全部/截止/课程/社团」。
- **印记**：6 个私人成就（提前一步 / 深潜者 / 收束者 / 本周建筑师 / 校园串联者 / 生活不漏接），按完成/专注/回顾/守时累计进度、解锁可佩戴称号；无积分、排名、排行榜、连续打卡；本地存储、删除任务不收回。
- **智能体建议**：任务编辑中显示识别标签（分类/优先级/时段/课堂模式）、建议提醒链与声音策略；可一键采用或手动修改；本地规则、可解释，不冒充大模型。
- **任务完成**：任务编辑顶部支持「标记完成 / 恢复未完成」，完成时记录时间、取消待触发提醒并同步印记进度。
- **快速录入**：自然语言解析（纯规则），先显示可编辑识别结果，不确定时打开预填编辑弹窗，绝不静默猜测。
- **专注舱 / 3 分钟微起步**、**今日简报**、**晚间收束**（21:30 回顾）、课堂静音模式、勿扰时段、数据导入导出。

## 取舍记录

- **提醒链逐级开关**：实现了每一级的声音 / 全屏开关；「系统通知」为全局开关（不做逐级，避免弹窗过多）。
- **重复任务「仅此次/整个系列」**：仅此次会新建一条一次性任务、系列保持不变；删除范围同理。
- **内置提示音**：内置 5 段本地音频（晨钟 / 暖阳 / 轻铃 / 流云 / 静夜，随应用打包，命名依据音频内容特征，位于 `public/sounds/`）+ 3 个合成音（晨雾 / 深潜 / 夜航，Web Audio 实时合成，离线可用、无版权风险）。
- **分类绑定铃声**：实现按任务绑定铃声（`soundId`）；分类级绑定暂未做（任务级已覆盖核心诉求）。

## 浏览器限制

- 音频需用户首次交互后才解锁 `AudioContext`；到点若未解锁，全屏提醒会显示「点击播放声音」，不会静默失败。
- PWA 的 Service Worker 仅在 https / localhost 下注册，且**只缓存静态资源、不做后台定时**。
- Wake Lock、系统通知、震动依赖浏览器支持与用户授权；IndexedDB 在隐私模式可能受限。

### iOS / Android 后台限制（务必了解）

- **iOS（Safari / 添加到主屏幕的 PWA）**：页面切到后台或锁屏后，定时器会被**挂起**，到点提醒**不会**触发；系统通知也需用户主动授权。iOS 不允许网页在后台持续运行或播放音频。因此「锁屏后照常响铃」在 iOS 上**做不到**。
- **Android（Chrome / WebAPK）**：后台定时器会被节流（约每分钟一次），提醒可能**延迟**；锁屏后同样无法保证响铃。系统通知是补强手段，非实时闹钟。
- 结论：本应用是「**开着就准时**」的网页工具，不是系统级闹钟。需要锁屏/后台可靠响铃，请使用系统自带闹钟或原生 App。

## PWA

- `public/manifest.webmanifest`：名称、主题色、`standalone` 显示、192/512 PNG 图标、maskable 图标和 SVG 备用图标。
- `index.html`：manifest、theme-color、apple-touch-icon、`apple-mobile-web-app-title`，并启用 `viewport-fit=cover`。
- `public/sw.js`：**只做离线静态壳缓存**（index.html / manifest / 图标 / 构建产物），不涉及数据、不做后台定时器。
- 设置页提供「安装到主屏幕」：Android/Chrome 使用 `beforeinstallprompt`；iOS Safari 显示「分享 → 添加到主屏幕」说明；不自动弹窗。
- 需 https 或 localhost 环境；安装后从主屏幕全屏打开。页面关闭后仍然不能保证响铃，这是浏览器边界。

## 已知限制（P2，不阻断使用）

- **快速录入标题保留动词**：如「交实验报告」→ 标题仍含「交」，可手动编辑。
- **截止关键词「交」偏宽**：「交流 / 交换」等含「交」的词可能被预判为截止，可在预览一键切换为日程。
- **倒计时向下取整**：90 秒显示为「还有 1 分钟」（不足 1 分钟才显示秒）。
- **晚间收束卡片**：21:30 后出现，手机上可能部分遮住「开始专注」按钮行，可一键关闭。
- **「周三」在周三当天解析为今天**：若时间已过不会自动跳到下周，需手动改日期。
- **极短任务（≤15 分钟）触控面积**：时间轴视觉高度按分钟精确，靠透明命中区补偿到约 44px，属「分钟精度」与「触控面积」的折中。
